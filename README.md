# ClassPilot Free Preview

Public landing page for ClassPilot Free Preview.

- Intended Cloudflare Pages URL: `https://classpilot-free.pages.dev`
- The **Launch ClassPilot** button opens the hosted Google Apps Script ClassPilot web app.
- Repository is separate from `jasonjohnson.cc`.

## Cloudflare Pages settings

- Repository: `jasonjohnson75-cyber/classpilot-free`
- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`
- Root directory: leave blank

After deployment, test the landing page and then click **Launch ClassPilot** to confirm it opens the hosted setup wizard.
